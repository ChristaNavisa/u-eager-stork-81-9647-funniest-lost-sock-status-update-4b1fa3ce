Entry for [Funniest Lost Sock Status Update](https://make.fun/bounty/u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce) on make.fun.

The program writes one status update to `/output/entry.txt`: a lost sock reporting from inside the dog — the only witness to how it got there, and the dog won't say either. The gate requires 1–120 characters of UTF-8 text on one line; this entry is 56 characters on one line, no trailing newline. (An earlier draft of this note said 52; the file was re-measured at 56.)

> Inside the dog. Don't ask how. The dog won't say either.

Run with Node 22+:

```sh
node main.ts
```
